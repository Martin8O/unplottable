The iceberg

the visible novel · and the world-bible beneath it

Behind the 124,642 words a reader sees sits another 94,848 words of bible and design docs — characters, world-rules, the plot architecture, the style guide, the foreshadowing ledger. Nothing reached the page without a home in that bible, logged in the same step.

On tokens. Per-prompt token consumption was not tracked in the repository — git records prose and decisions, not model usage. As a floor, the 124,642 words of final prose ≈ 166k output tokens; but redrafts, the 94,848-word bible, the five review panels and every tool call make true consumption a large multiple of that. Real token telemetry would have to come from the Claude Code session logs, not from git.

In-story span. 22 March 2033 → 4 February 2034 — about ten and a half months, told across five parts. Git: +10,480 / −720 lines over 52 commits. One redacted cell on the map: SO 41 55.
